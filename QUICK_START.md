# Quick start

1. Install the plugin ZIP in QGIS 3.44+.
2. Enable Native, GDAL, and GRASS Processing providers.
3. Run the provider's Preflight algorithm.
4. Open **Mine Water & Infrastructure Resilience - Complete Screening**.
5. Choose a new run name and existing output parent folder.
6. Select the mine study boundary; leave CRS blank for automatic metre-based UTM.
7. Choose automatic sources or manual/authoritative-only mode.
8. Add facilities, receptors, monitoring points, roads, rail, streams, and flood layers if available.
9. Enter reviewed rainfall/runoff values only if screening volume is required.
10. Review risk weights and stream proximity, run, then inspect the HTML report and GIS layers.

Never reuse a non-empty run folder. Never treat public-data screening as final design.
